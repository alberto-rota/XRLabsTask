PART A

## **Implementation Task**
Your script should:
1. Load a DICOM file or DICOM series.
2. Extract the relevant spatial metadata:
    - `ImageOrientationPatient`
    - `ImagePositionPatient`
    - `PixelSpacing`
    - `SliceThickness` or slice spacing derived from slice positions
    - Slice order information
3. Compute the voxel-to-patient transformation matrix.
4. Identify the anatomical orientation of the volume axes.
5. Compute the transformation matrix required to express the volume in RPI convention.
6. Output the final transformation matrix and clearly state the transformation direction.

---

## **Required Deliverables**

### **1) Runnable DICOM Orientation Script**

Your repository should include a Python script or notebook that performs the DICOM orientation analysis and RPI conversion.

The script should be runnable with clear instructions, for example:

```
python dicom_to_rpi.py --input path/to/dicom/folder
```

---

### **2) Transformation Outputs**
Your run should produce:

- Original DICOM orientation metadata OK
- Voxel-to-patient transformation matrix OK
- Detected anatomical orientation of the volume axes OK
- Transformation matrix required to express the volume in RPI convention OK
- Final transformation matrix OK
- Clear statement of transformation direction OK

---

### **3) Documentation**
Include a short explanation of:
- How the DICOM spatial metadata is used
- How the voxel-to-patient matrix is computed
- How RPI conversion is handled
- Any assumptions or limitations



PART B 

# **PART B: Registration of the Transformed 3D Model to Stereo Video and AR Projection**

## **Goal**

Using the transformed volume from Part A, first segment the skin/external patient surface and generate a 3D surface mesh. External software may be used for this step if the workflow is documented.

Then, implement a Python pipeline that registers the transformed pre-operative 3D model to the intraoperative stereo annotated landmarks for validation and projects the registered model into the image feed.

This task represents the next step of the navigation pipeline: connecting the transformed pre-operative anatomical model to the live microscope/exoscope view.

---

## **Inputs**

The candidate will be provided with:

- A video stream of left and right camera (surgical_navigation_task.avi)
- Stereo camera calibration parameters
- A DICOM file (Aneurysm MRI-20260520T145226Z-3-001)

---

## **Outputs**

Return visual and quantitative outputs showing:

1. Detected features and stereo matches
2. Triangulated 3D landmarks
3. Corresponding landmarks on the transformed 3D model
4. Estimated registration matrix
5. Registration or reprojection error
6. Projected overlay on the left and/or right video frame
7. A short discussion of assumptions, limitations, and failure cases

---

## **Implementation Task**

Your pipeline should:

1. Load synchronized left and right video streams.
2. Load the transformed volume, mesh, or landmarks produced from Part A.
3. Detect anatomical, geometric, synthetic, or manually initialized features in the left and right images (the candidate is free to choose the features).
4. Match corresponding features between the stereo views.
5. Detect, define, or manually annotate corresponding landmarks on the transformed 3D model.
6. Estimate the registration transformation between the transformed 3D model coordinate system and the stereo camera coordinate system.
7. Project the registered 3D model and/or specific selected anatomical structures into the left and right image feed.
8. Output visualizations and quantitative error metrics.

---

## **Implementation Requirements**

The implementation should include:

- Camera intrinsic matrices
- Stereo extrinsic transformation
- Feature detection and matching
- Stereo triangulation
- 3D-to-3D registration
- Homogeneous transformations
- 3D-to-2D projection
- Overlay visualization

Manually selected landmarks are acceptable if fully automatic anatomical feature detection is not feasible. The candidate should clearly explain how/why the method could be extended to real anatomical features in a surgical setting.
